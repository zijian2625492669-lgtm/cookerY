# cookerY 视觉基调说明（v1）

2026-10-26 定稿。之后所有页面、组件都按这份来，改基调先改这里。

## 1. 一句话
「厨房手账」：像一本摊在灶台边、被翻得有点旧的手写菜谱本。温暖、安静、好上手，不像外卖 App 那样花哨。

## 2. 设计原则
1. 手机优先：按 iPhone / 安卓竖屏单手操作设计，桌面端只是居中放大（最宽 520px）
2. 做饭时能用：字大、按钮大、手上有油也点得准（触控区不小于 44px）
3. 内容是主角：颜色只用来点重点，大面积留给米白底和文字
4. 少即是多：一屏只做一件事，没有广告式的徽章、红点和弹窗

## 3. 颜色
| 名称 | 变量 | 浅色 | 深色 | 用在哪 |
|---|---|---|---|---|
| 纸张底色 | --paper | #F6F1E8 | #1B1815 | 页面背景（带细微颗粒） |
| 卡片 | --card | #FFFCF6 | #25211D | 卡片、输入框、底栏 |
| 墨色 | --ink | #2A231E | #F1E9DD | 正文、标题 |
| 次要文字 | --muted | #8C7F73 | #A39686 | 说明、时间、作者 |
| 分隔线 | --line | #E7DDCE | #3A332C | 边框、虚线分隔 |
| 番茄红 | --tomato | #D9573B | #E8735A | 主按钮、选中、步骤序号、进度条 |
| 番茄浅 | --tomato-soft | #F7E1D8 | #3B2620 | 序号底、聚焦光圈 |
| 香草绿 | --herb | #6E8F5B | #6E8F5B | 标签文字、食材已备好的勾 |

规则：
- 番茄红是唯一强调色，一屏最多一个红色主按钮
- 绿色只表示“完成 / 标签”，不当按钮色
- 深色模式跟随系统自动切换，不单独做开关

封面占位色（没照片时用，渐变 + emoji）：番茄 #F4B9A6→#E8735A、蜂蜜 #F3D29A→#D9963B、青菜 #C9D8B6→#7E9F6A、麦子 #F1E3B8→#C9A24E、芒果 #FBD38D→#F08A4B、紫苏 #D7C6E8→#9479B8

## 4. 字体
| 用途 | 字体 | 字号 / 字重 |
|---|---|---|
| 大标题（页面名） | 宋体：Songti SC / 思源宋体 Noto Serif CJK SC | 32px / 700 |
| 菜名（详情页） | 宋体 | 30px / 700 |
| 卡片菜名 | 宋体 | 17px（首张大卡 20px）/ 700 |
| 小节标题（食材、步骤） | 宋体 | 20px / 700，右侧接虚线 |
| 正文、步骤 | 系统黑体：苹方 / HarmonyOS Sans / MiSans / 思源黑体 | 16px，行高 1.75 |
| 说明文字 | 系统黑体 | 12–13px，次要色 |
| 做菜模式步骤 | 宋体 | 26px / 600，行高 1.6 |

规则：
- 宋体只给“标题和菜名”，营造手账感；正文一律黑体，保证易读
- 不引入网络字体（国内加载慢），只用系统字体栈
- 输入框字号固定 16px，防止 iOS 聚焦时自动放大

## 5. 形状、间距、阴影
- 圆角：卡片 22px，输入框 14px，按钮 16px，标签和搜索框全圆（999px），详情页内容区顶部 28px
- 页面左右边距 18–20px；卡片间距 14px；小节之间 28px
- 阴影统一一套：`0 1px 2px rgba(60,40,20,.06), 0 8px 24px rgba(60,40,20,.08)`，暖棕色调，不用纯黑
- 分隔一律用虚线（dashed），像本子上的格线

## 6. 组件
- 底部导航：悬浮胶囊，半透明毛玻璃；左「菜谱」右「我的」，中间番茄红圆形「＋」凸出，新建菜谱
- 搜索框：全圆角白底 + 阴影，左侧放大镜
- 标签筛选：横向滑动的胶囊，选中变墨色实底
- 菜谱卡片：两列网格，第一张通栏大卡（16:9）；方形封面 + 宋体菜名 + “时长 · 作者”
- 详情页：上方大封面（返回、编辑为悬浮圆形按钮），下方内容区像纸张一样盖上来；信息胶囊（⏱ 时长、🍽 份量、✍️ 作者）
- 食材清单：白卡片，每行可点，点一下打绿勾并划掉，用于备菜
- 步骤：番茄浅底圆形序号 + 正文
- 主按钮：番茄红实底、52px 高，带红色柔光阴影；次按钮：白底虚线边
- 做菜模式：全屏一步一页，大号序号（01、02…）、大字、顶部进度条，保持屏幕常亮
- 编辑页：顶部「取消 / 标题 / 保存」，保存用番茄红文字；食材一行三格（名称 / 用量 / 单位）

## 7. 图标与图片
- 图标：线性描边，1.8px，圆头圆角，跟随文字颜色；不用填充图标
- emoji 用作菜的“表情”和信息胶囊前缀，保持亲切
- 接入照片后：封面 4:3（列表方形裁切），上传前压缩到 1MB 内；没照片继续用渐变 + emoji

## 8. 文案语气
- 像两个人之间说话：“今晚做点什么”“进厨房”“记一道新菜”“加一样食材”
- 不用“提交”“操作成功”这类系统腔
- 空状态给一个动作：“还没有这道菜 → 记一道新的”

## 9. 手机适配要点
- `viewport-fit=cover` + 安全区留白（刘海、底部横条）
- 支持“添加到主屏幕”（manifest + apple 相关 meta），像 App 一样全屏打开
- 主题色跟随浅 / 深色
- 点击有轻微缩放反馈（卡片 0.97、按钮 0.98），去掉安卓默认点击高亮

## 10. 代码对应
- 所有颜色、圆角、阴影、字体都在 `src/styles.css` 顶部的 CSS 变量里，改基调只改这里
- 封面渐变在 `src/components/Cover.tsx`
- 底部导航在 `src/components/TabBar.tsx`
- 新组件优先复用 `.card` `.chip` `.btn` `.field` `.pill` 这些现成类

## 11. 不要做
- 不加第二个强调色，不用纯黑纯白大色块
- 不用网络字体、不放外链图片（国内可能打不开）
- 不在列表页塞太多信息：卡片只放封面、菜名、时长、作者
- 不做小于 44px 的点击区域
